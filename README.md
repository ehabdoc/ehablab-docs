medical laboratory science students.

## Contents

- `index.html` — the whole guide in one file: CSS, JS and both languages inline. No build step,
  no dependencies, no CDN. Open it from disk and it works.
- `assets/logo.png` — hero mark and favicon.
- `screens/` — the figures.

## Note

The page is a copy published for hosting. The app itself, its question bank and its build
pipeline live in a private repository. The figures illustrate the app's screens at version
1.0.0+1; the numbers quoted in the guide come from that build.

Nothing here is medical advice — the app is a study tool for the MLS exam.
